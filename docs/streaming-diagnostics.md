# 流式输出链路诊断

## 固定复现实验

固定问题：

> 请详细介绍光刻工艺从晶圆准备到显影检查的完整流程、关键控制参数和常见缺陷，分章节回答

修复前在 `20260720-7` 上记录到 2996 个 `answer_delta`、5380 个正文字符。正文首分片在 15.525 秒到达，正文阶段最大服务端分片间隔为 163 ms，最终流式字符与结果字符完全一致。该数据排除了正文阶段模型长停顿和服务端丢分片，主要瓶颈是浏览器以 24 至 32 ms 间隔反复解析并替换完整 Markdown DOM，同时每帧最多只消费 16 个字符。

## 分段指标

- 模型流：`first_content_ms`、`max_content_gap_ms`、`content_delta_count`、`content_chars`、`stream_duration_ms`。
- 服务端：首个答案入队、最大入队间隔、最大队列等待、最大 SSE yield 间隔、答案事件数和字符数。
- 浏览器：读取分片数、最大读取间隔、最大缓冲积压、渲染帧数、最大和总渲染耗时、后台恢复次数、最终一致性。
- metadata 日志只保存上述聚合数值，不保存回答正文。浏览器遥测接口使用严格字段校验，额外字段会被拒绝。

`OBS-017` 将 Run 级 Trace 统一拆为 `context`、`routing`、`retrieval`、`tools`、`synthesis`、`stream` 六个命名阶段。`retrieval` 只累计知识检索，`tools` 排除知识检索后的业务工具耗时，`synthesis` 累计上下文以外的回答模型调用，`stream` 使用首个至最后一个服务端 SSE `answer_delta` 的实际输出区间，不再以端到端请求耗时冒充流式阶段。监控摘要为每阶段提供 Run 明细及 P50/P95；不适用或旧日志无法恢复的阶段返回 `null`，不伪造为零。

## 修复策略

浏览器缓冲改用游标消费，避免反复移动整个字符数组。活动流按积压量自适应消费，约每 28 至 32 ms 推进一次：活动阶段每帧最多 24 字，服务端结束后的积压排空每帧最多 32 字。标签页恢复可见时立即补绘。连续 1.5 秒没有新答案分片时仅显示“模型继续生成中”，不伪造输出。

最终正文仍以服务端 `result.answer` 为准。流式缓冲需要满足突发长文本不丢字、不重复，规范化后的最终正文可以替换不兼容的临时流。

## 增量 DOM 修复

`UX-020` 降低了刷新频率和缓冲排空时间，但仍会在每一帧重新解析并替换截至当前的完整 Markdown，长回答的累计工作量仍接近 O(n²)。`UX-022` 将流式正文拆成稳定区和活动尾部：遇到代码围栏外的闭合块边界后，该块只解析并追加一次；后续帧只替换尚未闭合的尾部。服务端最终结果到达后仍执行一次完整权威渲染，因此临时分块不会改变最终 Markdown 结构。

2026-08-01 使用 Windows Chrome 150、Playwright CDP、固定光刻长问题和真实 DeepSeek 流执行浏览器回归：

- 3541 个 `answer_delta`，6114 个流式字符，`final_match=true`。
- 186 个渲染帧，稳定区追加 37 次，活动尾部替换 186 次，流重置 0 次。
- 活动尾部最大 350 字；总渲染耗时 37.7 ms，单帧最大 0.7 ms。
- 100 ms 采样期间正文发生 144 次可见推进，最终页面没有横向溢出。

这些指标由真实浏览器的 `browser_stream_summary` 上报，只包含长度、次数和耗时，不包含回答正文。

## 自然呈现回归

`UX-023` 在增量 DOM 基础上补齐阅读体验：助手正文改为透明无边框阅读流；未完成的标题、列表符号和代码围栏暂不显示；生成光标附着最后一段可见文字；只有用户仍位于底部附近时才自动跟随滚动。最终回答仍由服务端权威正文重新渲染，来源与复制功能不变。

2026-08-01 使用 Windows Chrome 150 和 Playwright CDP，将 2135 字 Markdown 作为单个浏览器读取分片注入，模拟代理结束时大量文本同时到达：

- 缓冲积压 2135 字，通过 67 个渲染帧平滑排空，持续 2026.5 ms。
- 100 ms 采样得到 21 个样本，其中 20 次正文继续推进；单帧最大推进 32 字。
- 稳定块追加 44 次，活动尾部最大 56 字，流重置 0 次。
- 总渲染耗时 16.8 ms，单帧最大 1.0 ms，`final_match=true`。
- 助手正文实际样式为透明背景、0 像素边框、0 像素圆角，桌面与 390 像素宽移动端均无横向溢出。
