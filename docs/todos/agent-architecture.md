## 答案综合灵活性改善（2026-09-17 新增，实施中）

目标：严格约束生产事实与引用，灵活组织用户答案。以下是产品行为改善，不是纯结构重构；`AGENT-040` 已于 2026-10-15 完成，`AGENT-041`、`AGENT-042` 已于 2026-10-16 完成，`AGENT-043`、`AGENT-044` 仍待实施。适用当前内部单机 PoC，不新增企业级基础设施，不激活 `AGENT-039` 或 `REF-025`。

共同边界：保持真实引用、制造范围/时间/粒度一致性、主范围与背景证据区分、模拟数据披露；不得把模型知识当作生产事实。`ready` 确定性工具执行与非 ready 工具循环保持原有边界，`not_applicable` 的直接回答继续兼容。答案格式变化不等于事实验证能力增强，不宣称已实现通用数值核验。

- 每项独立提交；出现引用、范围、旧结果读取或重复工具执行回归时不得合入。契约快照只能在说明行为变化并经审查后更新，不能为通过测试直接重录。回退时保留既有结果读取能力，不删除历史运行数据。
