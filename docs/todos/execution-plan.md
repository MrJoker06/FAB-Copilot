# 非企业级 TODO 执行计划

状态基线：`experiment/parallel-platform`，2026-08-13。

本计划只安排当前单机样例和产品能力建设。企业 SSO、真实制造系统、分布式数据基础设施、多实例治理、网关和生产部署统一暂缓，未经重新确认不进入开发。

完成状态仍只在各分类 TODO 中使用 `[x]` / `[ ]` 维护；`OPTIONAL` 为可选候选/不一定需要，不使用勾选状态、不排期、不构成依赖，只有用户明确激活后才转为 `[ ]`。本文件只维护执行顺序和范围，避免形成第二套完成状态。

## 执行规则

1. 严格按顺序一次只实现一个任务编号，不并行混合多个功能。
2. 开始前确认工作区干净、依赖任务已完成，并记录基线测试结果。
3. 每个任务必须包含实现、针对性测试、必要文档和对应 TODO 状态更新。
4. 一个任务一个提交，提交标题包含任务编号，例如 `feat(AGENT-009): add intent router`。
5. 针对性测试通过后才能提交；每个阶段结束时运行完整 Python 回归和已有浏览器回归。
6. 未满足验收门槛时保持 `[ ]`，不得以“主体完成”或“文档完成”代替完成。
7. 发现企业级依赖时先记录阻塞，不扩展本期范围。
8. 发布或标签前、依赖或 Python/FastAPI/SQLite 升级、Schema/API/认证/RAG/流式重大变化，或累计约 5 个 feature/fix 后，必须运行完整测试审计。
