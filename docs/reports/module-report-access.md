# 报表目录的部门可见范围

开发基线为 PE / EE 值班工作区的 `99e252e`。首版在本地验证，由平台管理员统一维护。打开「管理后台 → 报表目录」即可配置。

1. 编辑文件夹，填入归属部门和额外开放部门。例如归属「光刻」，同时开放给「质量」。归属表示目录所属部门及其查看范围，配置权归平台管理员。
2. 点击「应用」，再点击「保存目录」。预览读取已保存的版本。旧目录和未填写部门的根级文件夹按公共目录处理。
3. 在预览框输入一个或多个部门。输入「质量」可查看向质量开放的报表链接，留空可查看普通用户当前可见的公共目录。预览使用管理员凭据，仅对本次请求生效。
4. 子文件夹继承上级限制。设置额外规则后，访问者在每一级受限目录都需至少命中一个所属或开放部门。停用报表在所有预览中隐藏。移除共享部门并保存后，新查询立即使用新规则。

服务端在返回链接前过滤目录，普通入口在当前演示身份环境使用公共范围。只有管理员可使用模拟部门预览。公司登录接入后，授权输入应来自服务端认证的成员关系。身份接入前使用合成目录测试。

该功能控制前台可获取的报表标题、描述和链接。链接对应报表的内容和下载权限由目标系统实施。MES 查询遵循原数据源的访问口径。试点范围以外的 Tool 执行、Skill 加载、RAG 召回和旧结果回读授权由 GitHub #3 跟踪，启用前须逐一验证。

回归入口为 `tests.test_duty_workspace_management`、`tests.test_identity_boundary`、`tests.test_refactor_contracts` 和 Playwright 的 `tests/e2e/duty-management.spec.js`。OpenAPI 冻结契约新增管理员预览路由、部门列表请求和文件夹权限字段，后台 DOM 契约增加五个配置及预览元素。

## 资料区与报表区分别配置（2026-11-24）

「报表目录」按文件夹维护可见范围。「共享资料」按资料区维护共享上传的 SOP 和历史 case。两处可以使用同一部门名称，授权各自保存。制程和岗位是筛选条件。

- 通用资料区固定对所有部门开放。已有共享上传沿用通用区，新资料在提交时确定目标资料区。公开的值班样例和原案例库继续通过各自来源在通用区展示，后台的移动、预览及计数针对共享上传。
- 管理员在「共享资料 → 配置部门资料区」创建归属部门，可添加额外可见部门。点击已有部门的「编辑」可撤销共享。管理员可以直接上传到目标区，也可以打开已有资料，修改所属资料区或停用。
- 值班端提供资料区筛选。用户只能选择有权访问的区上传。新上传、目录、正文和原文下载均在服务器检查范围，上传者也受撤销约束。现有演示身份没有受信部门，普通页面仅显示通用区。管理员可输入部门组合预览授权后应可见的资料区和已发布资料。
- 区域和资料归属随共享资料的 SQLite 库持久化。无归属记录代表通用；旧版客户端编辑资料时省略归属字段会保留原位置。已归类的资料在读取时使用该区当前的授权。企业登录后需由服务端提供部门成员关系。

本轮 WSL 管理、身份与契约专项共 20 项通过；Windows 管理和身份专项 11 项通过，HTTP 和知识上传系统测试 28 项通过。Windows Chromium 两条管理流程通过，覆盖资料移区、撤权和直接受限上传。两套边界和仓库检查通过。Windows 完整门发现 1611 项，非系统阶段 1520 项执行完毕（含 4 项跳过），随后因既有系统模块耗时清单缺项退出。本轮没有验证企业身份或调用真实模型。
