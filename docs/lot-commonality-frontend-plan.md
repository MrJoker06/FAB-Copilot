# Lot 相关性分析 · 前端改动计划

状态为待评审。基线为 `feat/pe-ee-duty-workspace` 的 `4711c13`。配套的[后端计划](lot-commonality-backend-plan.md)定义计数、数据能力、结果引用及双方共用的八批次验收样例。

## 1. 工程师要完成的操作

在左侧「基础报表」下方增加一级入口「相关性分析」。PE / EE 从异常现象出发，手动粘贴一组 lot，即可查询其共同加工经历。需要比较时，再手动添加同期异常、历史异常或正常参考组。异常描述选填，工程师无需创建 case 或提供公司系统单号。完成的标志是工程师能从一项共性点到具体 lot、实际过站记录及数据缺口，也能将同一选择交给右侧助手。

## 2. 页面设计

| 页面区域 | 操作与展示 | 验收要点 |
| --- | --- | --- |
| 输入组与范围 | 默认「本次异常」。支持逐行输入及粘贴 Excel 单列，展示组内去重结果。可增删对比组、自定义组名和用途。可选加工时间范围、异常截止时间或截止工序；提交前显示所选范围和时区 | 仅有主组即可查询。跨组重复的 lot 保留组籍并标出交集。查询返回后分别展示可分析、未找到、资料不足等服务端允许公开的状态 |
| 共性结果表 | 每行显示维度、具体发现、各组命中／确认未命中／未知数、分母。支持按维度、全部共有／部分共有筛选。时间分析显示实际时间窗；等待时间显示单位；返工显示发生在哪一站 | 一组即可得到可展开的结果。两组左右并排，组名始终可见。点击任意计数可查看对应成员，包括未知项及原因 |
| Lot 矩阵与路径 | 行为 lot，列按当前维度展示机台、腔室、recipe 等。切到路径视图，按实际过站顺序展示分叉、返工和重复过站 | 同次分腔可在一个过站下列多个腔室，分别显示已知片数；同站返工另列。来源只能证明用过某腔时，注明粒度 |
| 履历明细 | 由候选行或矩阵单元格进入，显示命中依据、来源、加工时间、层别／工序、机台及可用字段。支持有界分页和返回原选择 | 汇总按 lot 计，明细保留每次过站。缺字段、记录截断、来源故障与零命中有不同提示；无证据说明原因 |
| 值班智能助手 | 使用现有右侧助手。「让助手分析」带入分析版本、组、候选和已选筛选，在输入框旁显示可移除的范围。助手查询所得的结果带「在相关性分析中打开」 | 问“CH-B 且返工的是哪些 lot”能打开匹配清单。切换批次后，旧回答仍指向原结果；引用失效时提示重新查询 |

默认进入页面展示输入区。发起查询后保留组和范围，提供加载、部分返回、无共同项与查询失败状态。改动输入后将表中旧结果标明为上次查询；较早请求晚返回时不得替换新结果。页面返回、浏览器前进后退和直接打开入口均恢复对应视图。地址只带受控结果引用，避免将 lot 清单写入 URL。

## 3. 分步交付

| 步骤 | 开发内容 | 独立验收 |
| --- | --- | --- |
| F1 · 导航与输入 | 核对现有服务端页面路由、初始激活项及 `app/static/index.html`、`app/static/app/bootstrap.js`、布局控制器。接入一级页面和组编辑器 | 从基础报表进入、刷新、前进后退均停在预期页面，无制造总览闪回。输入重复、空行、跨组相同 lot 均可核对 |
| F2 · 结构化结果 | 用后端计划的固定样例驱动共性表、矩阵、路径和明细。前端只渲染契约返回的计数与状态。开发用合成展示资料可放根目录 `display_mock_data/`，实际查询走服务端 | 用固定样例在浏览器完成“6 个命中 → B → 同次分腔 12/13 片”和“1 个未知 → H → 缺腔室记录”。关闭助手仍能完成两条操作 |
| F3 · 接实际查询 | 接入分析、候选成员及明细分页接口。处理超限、局部资料不足、权限拒绝、过期、旧请求晚返回 | 由受控测试来源跑真实 HTTP，逐项核对页面分子、分母、成员及原始过站。服务端失败时页面报告失败 |
| F4 · 双向助手与联调（已完成，2026-11-24） | 页面「问助手」写草稿和可移除的引用标签，以 `analysis_ref` 结构化字段传递；助手回答中的引用可回开同一版本并回填输入区 | 浏览器验证创建后回开、页面发问、移除标签、无权或失效引用入库前拒绝、样例与失效结果禁挂（`tests/e2e/lot-commonality-chat.spec.js`）。与后端共同签收[契约](lot-commonality-contract.md) |

## 4. 测试与交接

输入处理和请求竞态用现有 Node 测试。视图往返、矩阵下钻和助手跳转用 Playwright。按[测试策略](testing-strategy.md)运行受影响的入口，并在 Windows 和 Linux/WSL 启动后抽查一级页面。交付浏览器用例、可供工程师试用的合成输入，以及一次实际 HTTP 查询到明细的验收记录。界面模拟数据可独立验收 F1/F2，实际联调结果单独记录。
