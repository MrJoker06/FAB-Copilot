# 值班工作台页面展示资料

本目录仅包含人工编写的合成资料，用于展示 PE／EE 值班工作台。它不包含公司数据，不代表真实设备、告警、报表或批准生效的 SOP；页面按用户要求不额外显示演示标识。

- `catalog.json`：六个基础报表入口、三份 SOP、三个历史案例及可选 Autosystem 地址。
- `reports/`：可以直接打开的六份静态报表，独立于业务查询和数据库。
- `report.css`：静态报表的公共样式。

基础报表卡片的 `url` 可替换为获准访问的公司报表地址；`autosystem_url` 当前为 `null`，点击入口明确提示尚未配置。只接受相对根路径或 HTTP(S) 地址，不使用凭据 URL、脚本 URL 或未经授权的公司系统地址。跨域目标系统自行认证，本项目不代理凭据或冒充已连接。

资料由 `/display_mock_data/` 静态路径公开提供，因此这里**只能存放可公开展示的合成资料**，不要放真实公司文件、个人资料、凭据、日志或数据库。目录缺失时页面明确提示不可用；不会从业务库补造或静默替代。

这些资料不进入原知识库、RAG、Tool 注册或业务证据统计。“向值班智能助手提问”只将当前资料内容及编号、日期填入输入框，用户可检查后自行发送，不会自动发起模型请求。

接入公司系统时应替换资料来源并按公司身份、权限和可见性要求实施；不能将本目录的静态公开方式直接用于内部生产资料。
