# 光刻制程控制计划

## Overlay 与 Focus 控制

Overlay 和 Focus 应分别按产品、层别、曝光机和 reticle 分层监控。控制限来自稳定期数据，规格限不能代替控制限。出现固定方向偏移时优先检查 stage calibration 与对准系统；出现固定坐标重复缺陷时应检查 reticle 和产品公共因素。

## 曝光异常判定

单点超出 3 sigma、连续 7 点位于中心线同侧或跨多个产品在同一设备出现同方向偏移，应启动工程审查。只有单一产品异常时，需要先排除 reticle、版图密度和产品配方，不应立即认定曝光机故障。

## 设备与产品分层

设备相关问题通常跨产品、跨 reticle 出现；reticle 相关问题会跟随 reticle 移动；产品相关问题集中在固定层别或图形区域。缺陷图、设备时间线和交叉机台结果应共同用于归因。

## 恢复生产验证

Stage、光源或对准系统维修后，应完成安全联锁、校准、golden wafer 和首批加严量测。Overlay 与 Focus 均满足控制限，并由光刻设备和制程工程师共同签核后，才可恢复量产。
