# 制造数据与指标治理

## 指标定义

良率、通过率、异常数、周期时间和 Cpk 必须有统一口径。良率按 good_wafers/wafer_count 计算；工具 pass_pct 表示制程记录通过比例，不等同于最终电性良率。

## 时间与样本范围

每个报表必须显示起止日期、样本量和过滤条件。最近 N 天以当前日期为结束日期。完成批次和在制批次应分开统计，避免未来完成时间或重复批次进入历史指标。

## 数据质量

关键字段应检查缺失、重复、单位和时间顺序。设备 ID、recipe 和原因码必须使用受控字典。异常值不能静默删除，修正需要保留原值与审计记录。

## 权限与审计

查询、导出、配置变更和危险操作应记录用户、时间、范围和结果。完整 Agent 日志可能包含制造数据，只适合受控测试环境；生产环境默认记录元数据并限制访问。
