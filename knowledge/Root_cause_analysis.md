# 制造根因分析方法

## 问题定义

问题定义应包含对象、指标、基线、变化幅度、时间范围和样本量。使用“全部不合格”“设备很差”等结论性描述前，必须先验证数据是否支持该前提。

## 假设生成

按设备、产品、材料、方法、量测和环境生成候选假设。历史案例用于提供排查方向，不是直接证明当前问题具有相同根因。

## 假设验证

优先选择可证伪的检查：交叉设备、跨产品、维护前后、缺陷空间图和参数时间线。每个结论应明确事实、推断和待验证项，相关性不能替代因果。

## 防复发

纠正措施解决当前问题，防复发措施则更新控制计划、PM、报警阈值、检查表或培训。案例关闭时应记录验证周期和量化结果，便于后续复用。
