# 刻蚀制程控制计划

## 关键参数

ETCH 关键参数包括腔压、RF source/bias 功率、气体流量、温度、刻蚀时间和 endpoint 信号。CD、残留、选择比和均匀性必须与设备 trace 同步分析，不能只看最终 pass_flag。

## Endpoint 异常

Endpoint 时间变化而腔压、RF 和流量稳定时，应检查光谱窗口污染、传感器校准和检测 recipe。Endpoint 信号弱可能造成过刻或欠刻，恢复后必须使用监控片确认刻蚀速率和 CD。

## 腔体寿命管理

缺陷率应按清腔后累计片数分层。若 Residue、Particle 或 CD 变异随累计片数持续上升，应以风险和产能共同确定清腔周期，并验证清腔后的 seasoning 充分性。

## 异常批次处置

CD Shift 或刻蚀残留异常应隔离自上一次合格监控之后的相关批次。复检前确认量测系统正常；是否返工或报废由制程、整合和质量共同评估，Agent 不得自动执行处置。
